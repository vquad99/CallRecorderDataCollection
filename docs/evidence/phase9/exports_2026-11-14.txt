Found and fixed while testing
-----------------------------
- A very long export could have been taken for a stopped one and started a second time, the two
  writing the same object. Each try now writes its own object and says it is alive every 30
  seconds; a try that was overtaken writes nothing.
- The projects list was ordered by code: with more than one page of projects a project just
  created was not on the first page (the browser run failed on the build machine's 36 projects).
  The list is now newest first.

------------

frontend (Vite dev server, Node 22), Microsoft Edge driven by Playwright, nginx 1.28 for the web
server rules, gitleaks 8.21 for the secret scan.

The phone-call journey (frontend/journeys/phonecall.spec.ts), step by step
---------------------------------------------------------------------------
1. Super Admin gives the moderator an agent seat on the user page ......... "Agent seat saved."
2. A number the provider refuses: the card says the call could not be placed, with the
   provider's answer; Start call is offered again.
3. Start session, Start call: "On the call"; the history shows "TXCONTACT answered HTTP 200".
4. Close call is disabled until Participant A and Participant B are ticked on the checklist.
5. Close call without consent: refused with "Record consent for participant A and B...".
6. Consent given for both, note typed, Close call: the recording arrives by itself;
   "Recording stored: 8000 Hz, 1 channel(s), 12 s; delivery file made at 16000 Hz".
7. Listen plays 12 s to the end; the automatic check shows no failure; Send to QC: "Audio QC".
8. Phone calls page: the call is listed "Recording stored", the refused one "Call could not be
   placed"; figures 2 calls, 1 recorded, 1 not placed, 1 task sent to QC; checklist counted.
9. The recordings list carries both files; the details file has the call section (seat, note,
   checklist times).

Found by running it, and fixed (each has a test)
-------------------------------------------------
- Task page: Listen and "Download with consent form" never worked on a real server, for
  face-to-face recordings too: the recordings list carried no files (unit tests faked them).
- Every phone recording failed the automatic check (rule: 2 channels; recording: 1), so QC had
  to justify every pass.
- Ticking checklist boxes quickly lost ticks (four requests, last write won).
- The 5-second refresh rebuilt the call card: an open cancel form and its note were lost.
- A closed call could wait for ever when the provider could not be searched, and could not be
  cancelled.
- Phone width (375 px): the task page overflowed sideways by 393 px, the Phone calls page by
  108 px. Now 0 px on both (screens/06, screens/07).
- Dashboard: a React duplicate-key error with very small totals.
- Site: /.env, /.git/config and unknown files answered 200 with the app page.
